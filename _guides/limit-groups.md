# Limit groups

A limit group is a set of apps with rules about when they're paused or how long you can use them. It's the way to say "no social media during work hours" or "30 minutes of games a day."

## Create a limit group

1. Open the **Limits** tab and tap **Add**.
2. Name the group and choose its apps. An app can be in more than one group.
3. Add a rule set, or add one later.

## Rule sets: when, and what happens

Each group holds any number of **rule sets**. A rule set has two parts.

**When it applies** (the trigger):

| Trigger | Applies |
| --- | --- |
| **All day** | Every day, resetting at midnight. You can choose which weekdays. |
| **Schedule** | On the weekdays and between the times you choose. A window can run past midnight. |
| **Focus** | While an iOS Focus you've set up for it is on. See [Focus filters]({{ "/guides/focus-filters/" | relative_url }}). |
| **Location** | While you're at one of your [places]({{ "/guides/places/" | relative_url }}), or, if you choose "everywhere except", anywhere outside them. |

**What it does** (the mode):

- **Pause**: the apps are unavailable while the rule set applies.
- **Allow some time**: the apps work for the number of minutes you set, then they're paused. The allowance starts fresh each time the rule set applies again: each day for an all-day rule, each window for a schedule, each Focus session or visit for Focus and Location rules.

## Unpause

A rule set can offer a few unpauses. Each gives you 5 more minutes with the apps. The number resets the next time the rule set applies. An unpause only lifts the rule set that offered it. If another rule set is also pausing the app, the pause screen offers that rule set's options instead.

Using an unpause breaks your [streak]({{ "/guides/streaks/" | relative_url }}). Clearer tells you before you do it and never stops you.

## When several rules apply

See [How groups are applied]({{ "/guides/how-groups-are-applied/" | relative_url }}). In short: if any rule set is pausing an app, it's paused.

## Good to know

- Clearer doesn't show minutes used or minutes left. An allowance in progress reads "N min allowed."
- iOS can deliver schedule and location changes a little late. Limits may start or end seconds to minutes off.
- If iOS stops sending updates to Clearer, your apps become available rather than staying paused by mistake.
